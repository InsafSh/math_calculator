# MathCalc

Настольное приложение для математических расчётов с **прозрачными пошаговыми решениями** и визуализацией.
Цель проекта — инструмент для лабораторной и научной работы: точные вычисления (SymPy), проверяемый ход решения,
графики публикационного качества, экспорт результатов.

**Стек:** Python 3.11+, PySide6 (Qt), SymPy, NumPy, SciPy, Matplotlib, openpyxl.

---

## Запуск

```powershell
pip install -r requirements.txt
python main.py
```

На Windows можно запустить `run.bat` двойным щелчком.

## Что умеет сейчас

43 задачи в четырёх разделах; у каждого раздела есть справочник с формулами.

### Обработка эксперимента

| Задача | Что делает |
|---|---|
| Прямые многократные измерения | среднее, СКО, отсев промахов по критерию Граббса, коэффициент Стьюдента, учёт погрешности прибора по ГОСТ Р 8.736-2011, округление и запись результата |
| Косвенные измерения | символьные частные производные, квадратичное сложение погрешностей, граничная оценка, вклад каждой величины (диаграмма) |
| Аппроксимация МНК | прямая (с выводом формул), полиномы, экспонента, степенная, логарифмическая, своя формула с параметрами; взвешенный МНК по σy; доверительные интервалы параметров, R², χ²/ν, остатки, доверительная полоса кривой |
| Табличная функция | интерполяция (кубический сплайн / линейная), численная производная, интеграл методами трапеций и Симпсона |

Данные вводятся текстом, вставляются из Excel (табуляция, десятичная запятая) или загружаются из CSV/TXT/XLSX.

### Функции и графики

Графики нескольких функций с точками пересечения; полное исследование функции (область определения, чётность,
нули, асимптоты, экстремумы, перегибы, наибольшее и наименьшее значения); параметрические и полярные кривые
(длина, площадь); неявные кривые F(x, y) = 0; поверхности z = f(x, y) в 3D с картой линий уровня.

### Математический анализ

Пределы (подстановка, тип неопределённости, правило Лопиталя по шагам, односторонние пределы, численная проверка);
производные любого порядка, касательная и нормаль; частные производные, градиент, гессиан, якобиан; экстремумы
функций нескольких переменных (критерий Сильвестра); неопределённые интегралы с ходом решения (замена, по частям,
табличные) и проверкой дифференцированием; определённые и несобственные интегралы с численной проверкой;
двойные и тройные интегралы; ряд Тейлора; числовые ряды (признаки сходимости, сумма).

Формулы вводятся в привычной записи: `2x`, `x^2`, `sin x`, `ln x`, `lg x`, `√x`, `e^x`, `arctg x`.

### Аналитическая геометрия — 24 задачи

| Группа | Задачи |
|---|---|
| Плоскость | по точке и нормали; через 3 точки; в отрезках; через точку параллельно двум векторам; параллельно плоскости; перпендикулярно двум плоскостям; через прямую и точку; нормальное уравнение |
| Прямая в пространстве | по точке и вектору; через две точки; из общих уравнений |
| Взаимное расположение | две плоскости; прямая и плоскость; две прямые |
| Расстояния и проекции | точка–плоскость; точка–прямая; параллельные плоскости; скрещивающиеся прямые |
| Пучок плоскостей | плоскость пучка через точку |
| Геометрия на плоскости | деление отрезка и центр масс; треугольник (стороны, медиана, высота, угол, биссектриса); прямая и точка |
| Кривые второго порядка | канонический вид с поворотом и переносом осей, фокусы, эксцентриситет, асимптоты, директрисы, вырожденные случаи |
| Комплексные задачи | плоскость ABC, прямая AD, перпендикуляр DH, параллельная плоскость, прямая из общих уравнений |

Для каждой задачи:
* форма ввода с примерами; допустимы дроби `1/2`, десятичные `2.5` / `2,5`, корни `sqrt(3)` / `√3`, `pi`;
* пошаговое решение с точными значениями (дроби, радикалы) и десятичными приближениями;
* 2D-чертёж или 3D-сцена (вращение мышью, виды XY/XZ/YZ), сохранение графика в PNG/SVG/PDF;
* копирование решения и сохранение в HTML/TXT;
* поиск по задачам (Ctrl+F), светлая и тёмная темы, решение по Ctrl+Enter;
* вычисления идут в фоновом потоке: окно не «зависает», долгий расчёт можно прервать.

## Структура проекта

```
mathcalc/
  core/              вычислительное ядро, без GUI
    common.py        разбор чисел, точное форматирование, оформление шагов
    expr.py          безопасный разбор формул (2x, sin x, ln x …) и перевод в NumPy
    data.py          таблицы данных (Excel, CSV, десятичная запятая), округление результата
    result.py        единый формат результата: Result, сцены 2D/3D
    experiment.py    обработка эксперимента: ГОСТ Р 8.736, косвенные измерения, МНК, табличные функции
    functions.py     графики, исследование функции, кривые, поверхности
    calculus.py      пределы, производные, интегралы, ряды
    handbooks.py     справочники разделов
    geometry/        аналитическая геометрия
  tasks/             реестр задач: поля ввода, примеры, функция решения (по модулю на раздел)
  plotting/          отрисовка сцен на matplotlib (используется GUI, тестами и экспортом)
  gui/               интерфейс PySide6: главное окно, страница задачи, виджеты решения и графиков
tests/               pytest: эталонные ответы, все задачи и примеры, отрисовка, GUI без дисплея
main.py              точка входа
```

### Как добавить задачу

Задача описывается один раз в модуле раздела в `mathcalc/tasks/`; форма и пункт меню строятся автоматически:

```python
register(Task(
    id="geometry.plane.point_normal", section="Аналитическая геометрия", group="Плоскость",
    title="По точке и вектору нормали",
    fields=[point3('M0', "Точка M₀", (1, -2, 3)), vec('n', "Вектор нормали", (2, -1, 4), ("A", "B", "C"))],
    solve=solve_function,          # dict значений полей -> Result(steps, summary, values, scene2d, scene3d)
    presets=[Preset("Пример 1", {...})],
))
```

Новый раздел — новый модуль в `mathcalc/tasks/`, импортированный в `mathcalc/tasks/__init__.py`.
