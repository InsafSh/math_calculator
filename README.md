# MathCalc

Настольное приложение для математических расчётов с **прозрачными пошаговыми решениями** и визуализацией.
Цель проекта — инструмент для лабораторной и научной работы: точные вычисления (SymPy), проверяемый ход решения,
графики публикационного качества, экспорт результатов.

**Стек:** Python 3.11+, PySide6 (Qt), SymPy, NumPy, Matplotlib.

---

## Запуск

```powershell
pip install -r requirements.txt
python main.py
```

На Windows можно запустить `run.bat` двойным щелчком.

## Что умеет сейчас

Раздел **«Аналитическая геометрия»** — 24 задачи:

| Группа | Задачи |
|---|---|
| Плоскость | по точке и нормали; через 3 точки; в отрезках; через точку параллельно двум векторам; параллельно плоскости; перпендикулярно двум плоскостям; через прямую и точку; нормальное уравнение |
| Прямая в пространстве | по точке и вектору; через две точки; из общих уравнений |
| Взаимное расположение | две плоскости; прямая и плоскость; две прямые |
| Расстояния и проекции | точка–плоскость; точка–прямая; параллельные плоскости; скрещивающиеся прямые |
| Пучок плоскостей | плоскость пучка через точку |
| Геометрия на плоскости | деление отрезка и центр масс; треугольник (стороны, медиана, высота, угол, биссектриса); прямая и точка |
| Кривые второго порядка | канонический вид с поворотом и переносом осей, фокусы, эксцентриситет, асимптоты, директрисы, вырожденные случаи |
| Комплексные задачи | плоскость ABC, прямая AD, перпендикуляр DH, параллельная плоскость, прямая из общих уравнений |

Для каждой задачи:
* форма ввода с примерами; допустимы дроби `1/2`, десятичные `2.5` / `2,5`, корни `sqrt(3)` / `√3`, `pi`;
* пошаговое решение с точными значениями (дроби, радикалы) и десятичными приближениями;
* 2D-чертёж или 3D-сцена (вращение мышью, виды XY/XZ/YZ), сохранение графика в PNG/SVG/PDF;
* копирование решения и сохранение в HTML/TXT;
* поиск по задачам (Ctrl+F), светлая и тёмная темы, решение по Ctrl+Enter.

## Структура проекта

```
mathcalc/
  core/              вычислительное ядро, без GUI
    common.py        разбор ввода, точное форматирование, оформление шагов
    result.py        единый формат результата: Result, сцены 2D/3D
    geometry/        решатели раздела «Аналитическая геометрия»
  tasks/             реестр задач: поля ввода, примеры, функция решения
    registry.py
    geometry.py      регистрация задач геометрии
  plotting/          отрисовка сцен на matplotlib (используется GUI, тестами и экспортом)
  gui/               интерфейс PySide6: главное окно, страница задачи, виджеты решения и графиков
tests/               pytest: эталонные ответы, все задачи и примеры, отрисовка, GUI без дисплея
main.py              точка входа
```

### Как добавить задачу

Задача описывается один раз в модуле раздела в `mathcalc/tasks/`; форма и пункт меню строятся автоматически:

```python
register(Task(
    id="geometry.plane.point_normal", section="Аналитическая геометрия", group="Плоскость",
    title="По точке и вектору нормали",
    fields=[point3('M0', "Точка M₀", (1, -2, 3)), vec('n', "Вектор нормали", (2, -1, 4), ("A", "B", "C"))],
    solve=solve_function,          # dict значений полей -> Result(steps, summary, values, scene2d, scene3d)
    presets=[Preset("Пример 1", {...})],
))
```

Новый раздел — новый модуль в `mathcalc/tasks/`, импортированный в `mathcalc/tasks/__init__.py`.
